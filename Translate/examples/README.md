# Example braille files

Load these with Connector's **Load** button. The Nemeth file needs no tick at all —
every line is wrapped in the BANA switch indicators `⠸⠩ … ⠸⠱`, so the file
announces itself. For the UEB file, tick **UEB Maths** (UEB maths is the same
code as UEB text, so nothing in the cells can mark it).

| `nemeth-maths.brf` | *(none — self-describing)* | 26 expressions |

The twelve `music-*` files above the Cologne melody were generated by
`BrlMusic/demo-pieces.mjs` (public-domain tunes; note data typed from the tune,
so no publisher's engraving is reproduced). None of them is hand-typed braille:
each is note data → MusicXML → the product writer → the product reader, and is
written out only if it reads back note for note with zero warnings — then the
written FILE is decoded again and re-read, so the BRF on disk is verified, not
just the cells in memory. Regenerate with `node demo-pieces.mjs --brf`.


They cover fractions (including nested and algebraic), powers, negative and
fractional indices, subscripts, square/cube/fourth roots, Pythagoras,
inequalities, scientific notation, πr² — and the **quadratic formula**.

Every line was generated by MathCAT (MathML → braille), so it is an authentic
transcription, and every line is verified to convert back to the correct
expression — nothing is shipped here that renders wrongly.

`COVERAGE.md` lists what does and does not work, including the known gaps
(functions like sin/log, Σ, ∫, matrices, |x|). Regenerate everything with:

    node connector/tools/coverage.mjs
